Lancement de la campagne de candidatures.

Lit le fichier data/emails/emails-prepared.json.

Pour CHAQUE offre du fichier, fais ceci :

1. Ouvre Gmail compose en naviguant vers :
   browsermcp_browser_navigate vers https://mail.google.com/mail/u/0/?view=cm&fs=1&to={EMAIL}&su={SUJET}

2. Attends 5 secondes puis capture un snapshot :
   browsermcp_browser_wait time=5
   browsermcp_browser_snapshot

3. Avant de remplir le corps, Lis l'offre correspondante et PERSONNALISE l'email :
   - Adapte le ton au secteur de l'entreprise
   - Vérifie la cohérence avec le poste exact
   - Ajoute un détail spécifique à l'offre si pertinent
   - Si un lien portfolio est disponible (champ "portfolio" du JSON), ajoute-le avant la formule de politesse
   - Garde un ton professionnel mais humain
   - Ne copie JAMAIS le CV directement

4. Remplir le corps du message :
   - Cherche le champ texte (textbox) dans le snapshot
   - Utilise browsermcp_browser_type avec le ref du champ et le corps personnalise

5. Attacher le CV :
   - Execute : powershell -Command "Invoke-RestMethod -Uri 'http://localhost:9011/upload' -Method Post -ContentType 'application/json' -Body '{\"filePath\":\"CHEMIN_CV\"}'"

6. Verifie la piece jointe avec un browsermcp_browser_snapshot

7. Si DRY_RUN=true (defaut) : STOP pour cette offre. Passe a la suivante.

8. Si DRY_RUN=false : Envoie avec Ctrl+Enter :
   - Utilise browsermcp_browser_type avec le ref du bouton "Send" et la touche Enter
   - OU utilise browsermcp_browser_keyboard pour envoyer Ctrl+Enter
   - IMPORTANT : Ne clique JAMAIS directement sur le bouton (timeout possible)

9. Attends 3 secondes avant de passer a l'offre suivante :
   browsermcp_browser_wait time=3

10. Enregistre le suivi dans l'Excel de tracking :
    Execute la commande :
    node -e "import('./scripts/tracking/tracker.js').then(m => m.appendRow({entreprise: 'ENTREPRISE', poste: 'POSTE', url_offre: 'URL_OFFRE', email: 'EMAIL_RECRUTEUR'}))"
    Remplace ENTREPRISE, POSTE, URL_OFFRE, EMAIL_RECRUTEUR par les valeurs de l'offre en cours.
    Le fichier data/suivi_candidatures.xlsx sera cree automatiquement s'il n'existe pas.

IMPORTANT :
- Si DRY_RUN=true (defaut), AUCUN email n'est envoye. Tu preparles juste.
- Pour l'envoi reel, l'utilisateur doit definir DRY_RUN=false dans .env
- Jamais d'envoi sans confirmation explicite de l'utilisateur
- Chaque email doit etre UNIQUE et personnalise pour l'offre
- Ne JAMAIS copier-coller le CV dans l'email
