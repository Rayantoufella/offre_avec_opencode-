Lancement de la campagne de candidatures.

Lit le fichier data/emails/emails-prepared.json.

Pour CHAQUE offre du fichier, fais ceci :

1. Ouvre Gmail compose en naviguant vers :
   browsermcp_browser_navigate vers https://mail.google.com/mail/u/0/?view=cm&fs=1&to={EMAIL}&su={SUJET}

2. Attends 5 secondes puis capture un snapshot :
   browsermcp_browser_wait time=5
   browsermcp_browser_snapshot

3. Remplir le corps du message :
   - Cherche le champ texte (textbox) dans le snapshot
   - Utilise browsermcp_browser_type avec le ref du champ et le corps du message

4. Attacher le CV :
   - Execute : powershell -Command "Invoke-RestMethod -Uri 'http://localhost:9011/upload' -Method Post -ContentType 'application/json' -Body '{\"filePath\":\"CHEMIN_CV\"}'"

5. Verifie la piece jointe avec un browsermcp_browser_snapshot

6. Si DRY_RUN=true (defaut) : STOP pour cette offre. Passe a la suivante.

7. Si DRY_RUN=false : Clique sur le bouton Envoyer :
   - Cherche le bouton "Send" ou "Envoyer" dans le snapshot
   - Utilise browsermcp_browser_click avec le ref du bouton

8. Attends 3 secondes avant de passer a l'offre suivante :
   browsermcp_browser_wait time=3

IMPORTANT :
- Si DRY_RUN=true (defaut), AUCUN email n'est envoye. Tu preparles juste.
- Pour l'envoi reel, l'utilisateur doit definir DRY_RUN=false dans .env
- Jamais d'envoi sans confirmation explicite de l'utilisateur
