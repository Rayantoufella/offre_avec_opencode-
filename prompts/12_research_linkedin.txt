Lance la recherche d'offres d'emploi avec les paramètres suivants :

1. Allez sur LinkedIn avec Browser MCP
2. Recherchez les offres avec les mots-clés fournis
3. Scrollez pour charger plus de résultats
4. Extrayez les informations de chaque offre
5. Générez un fichier Excel avec les résultats
6. Présentez le rapport final

Le fichier Excel sera créé dans data/offres_recherche.xlsx avec les colonnes :
- N°, Entreprise, Poste, Lieu, Contrat, Date publication, Email, Technologies, STATUT, Source, Lien
